How it works

Export your portal data, run locally, get a report. Your data never leaves your machine — no cloud, no telemetry, no API keys required.

FAQ

Do I need a Gemini / OpenAI API key?

No. The claim-note generator ships with marketplace-specific templates (Flipkart SPF, Meesho Claims Policy, Amazon SAFE-T) that work fully offline. Adding a Gemini key enables richer drafts, but is optional.

Does my data leave my computer?

No. Streamlit runs locally. The AI drafter only uses your data if you supply an API key and it goes directly to the provider you choose — never to us, never to a middleman.

What marketplace policies are covered?

Flipkart Standard Performance Framework (SPF), Meesho Claims Policy, Amazon SAFE-T, and standard courier slab disputes (Shiprocket, BlueDart, Delhivery, Ecom Express). Templates are included for weight disputes, lost RTOs, and damaged returns.

What's the video cutter for?

Warehouse unpacking videos (1 hour, 50–100 packages) get split into per-AWB clips under 8MB for marketplace uploads. Uses OpenCV + pyzbar for barcode detection. Falls back to mock mode if ffmpeg/pyzbar aren't installed.

Is it free?

Yes — MIT-licensed, open source, forever. There's no "starter plan" or "pro tier." Run it however you want, including commercially.
